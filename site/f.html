Hand over a file as a link

      
For SSH keys, kubeconfigs and .env files. The file is packed into the link after the #, which browsers never send to a server, so it isn't uploaded or stored anywhere. Add a passphrase and send it by a different channel.

How safe is this?

      

        

          
Nothing is stored

          
No server ever receives the file: not GitHub, not a paste site. This page's security policy blocks every network request, and you can check it in the page source.

        

        

          
The link is the secret

          
Without a passphrase, anyone holding the link can open the file. With one, the link alone is useless. It's AES-256 with a PBKDF2 key (250,000 rounds), the same as openssl enc -pbkdf2.

        

        

          
Expiry is a soft limit

          
The page won't open a link after its time is up, but someone who saved the link and decodes it by hand isn't stopped. Delete links after use, and rotate a key if a link leaks.
