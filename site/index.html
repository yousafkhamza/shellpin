        How it works

        Nothing is stored

        The page gzips the script and base64-encodes it into the command. This page's security policy blocks all network requests, so the script never leaves your browser.

        Safe to paste

        The whole script is decoded before anything runs. A cut-short or damaged paste fails the gzip checksum and nothing runs. Prompts still work.

        Guards inside the script

        The expiry date, the host lock and the secret prompts are written into the script itself, so they apply on SSH hosts and in containers too. They stop mistakes; they aren't a lock against someone who decodes the command by hand.

        Bash, sh and Python need base64 and gunzip on the machine you paste into (for pods and containers, on your own machine). PowerShell needs Windows PowerShell 5.1 or PowerShell 7. To hand over a key, use Share a file. For scripts you run often, a saved script gives a short curl command.
