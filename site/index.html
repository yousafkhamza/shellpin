    How it works

    Nothing is stored

    The page gzips the script and base64-encodes it into the command. This page's security policy blocks all network requests, so the script never leaves your browser.

    Safe to paste

    The server decodes the whole script before running anything. If the paste is cut short or damaged, gunzip's checksum fails and nothing runs. Prompts (read) still work.

    Expiry

    A check at the top of the script refuses to run after the time you pick (one year at most). It's a guard against reusing old commands, not a lock: the script can be decoded from the command by hand.

    Don't put passwords or keys in a script; anything in the command ends up in shell history. To hand over a key, use Share a file. For scripts you run often, a saved script gives a short curl command.
