    Publish a script
    
      
    
      
    This page has no server: publishing commits scripts/<name>.sh to the repository and the Pages workflow deploys it in about a minute. Everything here is public, and git history keeps old versions. Never put passwords, keys or tokens in a script; pass them at run time.
    

      
    
        
    
          
          
        
    
        
        
        
        
    
          
          
        
    

        
      

        
      
          Commit directly with a GitHub token (optional)
          
      Without a token, “Continue on GitHub” opens GitHub's new-file page with the script filled in. With a fine-grained token limited to this repository with Contents: read and write, this page commits for you. The token stays in this tab's session storage and is only sent to api.github.com.
      
          
      
            
            
          
      
        
      

        
      
          
          
        
      
        
      
      
      
    
      

    
      
      
      Good to know
      
      
      
        
      
          
      Quick or verified
      
          
      The quick command is a plain curl -fsSL … | bash -s --. The verified command reads the script into a shell variable, checks its SHA-256, then runs it with bash -c. Nothing is written to disk, and an edited script won't run until you copy a fresh command.
      
        
      
        
      
          
      Expiry
      
          
      A daily workflow rebuilds the site at 00:07 UTC, leaves out scripts whose date has arrived, and deletes them from scripts/. To renew, edit the # @expires line. A build fails if the date is more than a year after the build day.
      
        
      
        
      
          
      curl error 60
      
          
      unable to get local issuer certificate means the server's CA bundle is broken or a proxy re-signs TLS. Fix the trust store; don't use -k. On Amazon Linux or RHEL: sudo yum reinstall -y ca-certificates && sudo update-ca-trust extract.
